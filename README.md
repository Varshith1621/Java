Java Basics

This repository contains simple Java programs created to practice and understand core Java concepts.
It is intended for beginners who are learning Java syntax, structure, and basic programming logic.

How to Run

Make sure Java (JDK) is installed on your system.

Compile the program:
javac FileName.java

Run the program:
java FileName

Example:
javac Hello.java
java Hello

Purpose

To practice basic Java programming
To understand Java syntax and structure
To learn fundamental concepts such as variables and data types

Requirements
Java JDK 8 or above
Any code editor (VS Code, IntelliJ IDEA, Eclipse, etc.)
